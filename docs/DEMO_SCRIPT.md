# MovieMagic demonstration

1. Open the landing page and explain the fictional catalog and simulated payment scope.
2. Register a demo account. Try the same email in different casing to show duplicate prevention.
3. Log in and use location, title and genre filters. Pick Magic Screens Central and a future show.
4. Select two seats, deselect one, then reselect it. Show the subtotal and zero convenience charge.
5. Use demo UPI or Pay at Counter. Confirm the booking, then show the ticket ID, seats, payment state and notification status.
6. Open the ticket from My Bookings and show print preview. Return to the same show and confirm the seats are disabled.
7. Switch to a second demo account and verify the private ticket link returns a 404.
8. In the AWS console, show the EC2 profile, both table keys, the booking and its seat locks, and the matching SNS filter. Show a real email only after receipt.
9. Close with the Mermaid diagrams and explain how SQLite and DynamoDB enforce the same rules.
